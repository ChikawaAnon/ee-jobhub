# Project-005-ee-jobhub · 电气专业秋招整合站

面向「广东海洋大学 · 电气工程及其自动化 · 2027 届」的秋招信息整合网站。整合电网/发电/设计院、电气设备/工控、新能源/车企/电池、泛工科延伸四大方向的校招/实习/社招信息，多维筛选，一键直达官方投递入口，支持爬虫更新与**新企业自动收录**。

- 设计大纲：`docs/outline.md`（已确认，2026-08-29）
- 开源说明：后端 Python（FastAPI，模块化分层，全中文注释，见 `src/app.py` 头部架构图）；前端原生 HTML/CSS/JS 三件套（无构建步骤、老内核兼容）；数据全部来自公开渠道并标注来源，仅供个人求职学习使用

## 快速开始

1. 双击 `start.bat`（首次运行自动创建 venv 并安装依赖，需要联网）
2. 浏览器自动打开 `http://127.0.0.1:8322`
3. 点右上角「更新数据」触发爬虫抓取各数据源最新动态

## 每日定时更新

- 已注册 Windows 计划任务 `EEJobHub-DailyUpdate`：**每天 08:00** 自动运行 `daily_task.bat`（抓取→入库→生成简报到 `data/digest/`）
- 网站服务运行中时另有内置调度兜底：过了 8 点当天还没更新就自动补跑一次
- 手机/电脑上点「📋 今日简报」看当天增量：新开招企业、已收录企业新动态、14 天内截止、收件箱待处理
- 微信推送已预留位置未接入（`src/daily_update.py`），想加时接 Server酱/PushPlus 即可
- 电脑关机则当天任务顺延到下次开机（服务在线 8 点后自动补，或手动点更新）

## 功能

- **校招信息**：统计总览 + 搜索 + 多维筛选（批次/方向/状态/城市/届别/对口度/排序，含湛江/茂名/阳江粤西快捷选项）+ 企业卡片 + 一键直达官方投递入口 + 企业详情（薪资结构/电气对口备注/数据来源/岗位级链接）
- **时间线**：按报名开始/截止时间排布（未官宣的按预计月份自动分组），快速识别快截止企业
- **电气专区**：四大方向报考指南、笔试科目、广东本地重点企业、大四全年节奏表
- **数据维护**：「提交上新」手动补充 + 卡片编辑人工修正 + 爬虫分源更新（人工字段永不覆盖）+ 收件箱（未匹配公告一键转为企业）
- **🤖 自动收录**：爬虫发现**新企业**的校招/实习公告（标题含校招/秋招/春招/20XX届/实习/宣讲信号）→ 自动解析公司名建档上架（带「自动收录」标记，单次最多 15 家，同名去重），后续公告自动挂到该企业下；不相关的一键 🗑 删除并拉黑（不再被抓回）
- **免费微信分享**：① 生成分享长图 PNG（当前筛选结果绘制成图片，直接发微信）② 导出离线完整版网页 .html（整个网站打包成一个文件发微信，好友用浏览器打开即用；想给公开链接可把该文件拖到 netlify.com/drop 免费托管）

## 目录

```

```

## 使用提示

- 每天打开点一次「更新数据」即可同步广海大就业网新公告 + 新开招企业自动上架
- 「分享」前先筛选（比如选「湛江（粤西）」或「S级对口」），分享的就是当前筛选结果；给手机好友推荐用「分享长图」最稳，离线网页已做老版微信内核兼容，好友点开选「浏览器打开」即可
- 薪资与「预计时间」均为公开渠道聚合口径，投递前务必点卡片里的官方链接核对
- 部分央企（国网/南网/发电集团）批次以官网公告为准，9-10 月是报名高峰，建议每天刷一次时间线视图
