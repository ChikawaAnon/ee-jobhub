# 电气专业秋招整合站 · 设计大纲（Project-005-ee-jobhub）

> 状态：已经用户确认（2026-08-29）
> 用户画像：广东海洋大学 · 电气工程及其自动化 · 2027 届（大四）

## 1. 项目定位

面向电气工程及其自动化专业应届生的**秋招信息整合网站**：整合电网/发电/设计院、电气设备/工控、新能源/车企/电池、泛工科延伸四大方向的校招/实习/社招信息，多维分类筛选，一键直达官方投递入口，支持按钮触发爬虫更新。本地运行、架构预留部署。

## 2. 已确认需求

| 维度 | 决定 |
| --- | --- |
| 部署 | 本地优先（双击启动脚本），架构预留云部署 |
| 更新 | 页面「更新数据」按钮触发爬虫入库 + 手动「提交上新」兜底 |
| 功能 | 核心整合+筛选+直达投递；加时间线视图、电气专业知识增强（明确不做：简历生成器、投递状态跟踪） |
| 企业范围 | 电网/发电/设计院 + 电气设备/工控 + 新能源/车企/电池 + 泛工科，四大方向全覆盖 |
| 技术栈 | Python 全套：FastAPI + 爬虫 + 网页前端 |
| 投递直达 | 全部企业给官方校招入口，热门企业（30-50 家）维护到岗位级投递页 |
| 数据来源 | 企业官方渠道为准；牛客/应届生/国聘/海投网/广海大就业网补充，标注来源 |
| 薪资 | 多来源区间 + 结构说明 + 「仅供参考」标注 |

## 4. 数据模型（每家企业一条记录）

- **标识/分类**：id、name、alias（简称）、cat（大类）、sub（子类）、ctype（央企/国企/民企/外企/合资/事业单位）、industry
- **招聘信息**：batch（秋招/春招/实习/社招）、status（进行中/即将截止/未开启/已结束/常年招聘）、year（届别）、positions（岗位方向）、position_details（岗位级明细：岗位+城市+学历+岗位投递页）、apply_url（官方投递入口）、official_site、cities、start_date、deadline
- **薪资**：salary_text（区间口径）、salary_structure（结构说明）、salary_source（来源标注，全部带「仅供参考」）
- **内容**：desc（一句话说明）、ee_notes（电气对口备注：笔试科目/对口岗位/报考建议）、tags（S级对口/高度相关/广东有岗/本科友好/央国企 等）
- **数据治理**：sources（来源列表：类型+URL+日期）、last_verified（最后核验时间）、manual_overrides（人工修改过的字段，爬虫永不覆盖）、pinned（重点推荐）、news（爬虫抓到的公司动态）、updated_at

**字段保护规则**：爬虫只更新 batch/status/deadline/news/last_crawl 等可爬字段；salary_*、ee_notes、tags、pinned、apply_url、position_details 等人工维护字段一旦存在人工标记，爬虫永不覆盖。

## 5. 功能清单

**页面（三视图）**
1. **校招信息**（默认）：顶部统计卡片（公司总数/正在招聘/含秋招/含实习/即将截止）；搜索框；多维筛选（批次/大类/子类/状态/城市/届别/对口度/排序）；企业卡片列表（标签、城市、岗位方向、截止、简介、电气标注）；每卡「去投递」新标签直达官方入口；「提交上新」表单；卡片可编辑（人工修正）
2. **时间线**：按报名开始/截止时间排布的时间轴，快速识别快截止/未开启
3. **电气专区**：四大方向报考指南（笔试科目、对口岗位关键词、报考建议）、广东本地重点企业、静态内容

**全局**：详情弹窗（完整信息+数据来源+岗位级链接）、深色模式、响应式（手机可用）、更新按钮（进度+最后更新时间+分源结果）。

**API**
- `GET /api/companies`（支持 q/batch/cat/sub/status/city/year/tag/sort 参数）
- `GET /api/companies/{id}`
- `GET /api/stats`、`GET /api/meta`
- `POST /api/companies`（手动提交上新）、`PATCH /api/companies/{id}`（人工修正，记入 manual_overrides）
- `POST /api/refresh`（后台线程触发爬虫）、`GET /api/refresh/status`

## 6. 数据来源与爬取策略（务实分层）

- **Tier 1 结构化抓取**（requests 可爬）：广海大就业网、海投网、国聘、牛客公开页、应届生等静态列表页
- **Tier 2 动态渲染**（Playwright，可选依赖）：个别 JS 渲染官网，按需启用
- **Tier 3 无法自动抓取**（国网招聘平台等强反爬/需登录）：人工维护 + 直达官方链接 + 聚合渠道动态
- **合并策略**：更新前快照备份 → 按字段保护规则合并 → 每条数据标注来源与时间 → 单源失败不影响其他源，结果分源展示
- **合规边界**：仅抓公开页面、限速（≥2s）、标准 UA、不绕登录/验证码、个人自用不商用

## 8. 技术要点

- FastAPI + uvicorn（127.0.0.1:8322），数据存 JSON（量级 150 条，无需数据库），线程锁保证并发安全
- 前端原生 HTML/CSS/JS，hash 路由三视图，localStorage 存深色模式
- start.bat：检测/创建 venv → 装 requirements → 启动服务 → 自动开浏览器
- 部署预留：前后端同服务，上云只需换启动方式与绑定地址

## 9. 风险与边界

- 官方链接会失效：每条带「最后核验时间」，卡片可一键编辑修正，详情页保留官网首页兜底
- 薪资为聚合爆料：全部标注「仅供参考·来源」，不作承诺
- 爬虫对反爬站点无能为力：分源容错，失败源如实显示，人工「提交上新」兜底
- 本机环境：Python 3.12 由本项目管理（winget 用户级安装），start.bat 全自动配环境
